# JavaScript & Bootstrap Practice

A collection of daily frontend practice projects focused on learning Bootstrap through small, practical web pages and mini projects.

## About This Repository

This folder documents my ongoing practice with Bootstrap and basic JavaScript.

The primary objective is to strengthen my understanding of Bootstrap's responsive grid system, components, utilities, and layout techniques by building small web pages regularly.

I use JavaScript only when required to add basic functionality or interactive behavior to a project.

Rather than focusing on large applications, I aim to build a strong foundation through consistent practice, experimentation, and implementation of individual frontend concepts.

## Learning Objectives

- Understand Bootstrap's responsive grid system and breakpoints.
- Practice building responsive layouts using Bootstrap containers, rows, and columns.
- Learn to use Bootstrap components such as navigation bars, cards, forms, modals, and buttons.
- Apply Bootstrap utility classes for spacing, typography, colors, alignment, and display.
- Customize Bootstrap components using CSS when required.
- Understand how Bootstrap's JavaScript components work.
- Use basic JavaScript for DOM manipulation, event handling, and simple interactive functionality.
- Improve code organization, accessibility, and responsive design practices.

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structures the web pages using meaningful and semantic elements. |
| Bootstrap | Primary framework for responsive layouts, components, and utility classes. |
| CSS3 | Provides additional styling and customization beyond Bootstrap. |
| JavaScript | Adds basic functionality and interactive behavior where required. |
| Bootstrap Icons | Provides icons for navigation, actions, and visual elements. |

## Practice Approach

Each mini project is an opportunity to understand and apply specific frontend concepts.

| Practice Area | Focus |
|---|---|
| Bootstrap Layouts | Containers, grid system, columns, breakpoints, and responsive design. |
| Bootstrap Components | Navbar, cards, buttons, forms, alerts, modals, and other components. |
| Bootstrap Utilities | Spacing, typography, colors, sizing, display, and alignment. |
| Custom CSS | Component customization, hover effects, transitions, and visual consistency. |
| Basic JavaScript | DOM manipulation, event handling, form validation, and simple interactions. |

|---|
