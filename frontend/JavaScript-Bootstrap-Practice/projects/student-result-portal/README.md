# Student Result Portal

A responsive student result portal built using HTML, Bootstrap, Bootstrap Icons, and basic JavaScript.

## Objective

To practice Bootstrap's responsive layout system, components, and utility classes by building a student result portal.

The project also introduces basic JavaScript for handling user confirmation, button interactions, conditional execution, and dynamic page content.

## Features

- Responsive student portal header.
- Student academic information section.
- Bootstrap card-based layout.
- Result announcement button.
- Confirmation dialog before viewing results.
- Conditional result announcement and cancellation messages.
- Dynamic browser tab title.

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structures the portal and its content. |
| Bootstrap 5.3.3 | Provides responsive layouts, cards, buttons, spacing, and typography utilities. |
| Bootstrap Icons | Displays academic and interface icons. |
| CSS3 | Customizes colors and button hover effects. |
| JavaScript | Handles user confirmation, button events, and dynamic page content. |

## HTML Elements

| Element | Use |
|---|---|
| `<header>` | Contains the portal branding and academic year. |
| `<main>` | Groups the primary page content. |
| `<section>` | Organizes the introduction, result information, and feature cards. |
| `<article>` | Groups individual content cards. |
| `<h1>`–`<h3>` | Establishes the heading hierarchy. |
| `<dl>` | Represents student information as a description list. |
| `<dt>` | Identifies each student information field. |
| `<dd>` | Displays the corresponding student information. |
| `<button>` | Triggers the result announcement interaction. |
| `<footer>` | Displays the portal's copyright information. |

## Bootstrap Components and Utilities

| Component / Class | Use |
|---|---|
| `container` | Provides a responsive content wrapper. |
| `row` and `col-md-6` | Organizes content into responsive columns. |
| `card` and `card-body` | Structures the result information and feature cards. |
| `d-flex` | Creates flexible layouts for alignment. |
| `justify-content-between` | Places content at opposite ends of a flex container. |
| `align-items-center` | Aligns items along the cross axis. |
| `gap-3` | Adds spacing between flex items. |
| `py-5` and `mb-4` | Applies vertical padding and bottom margins. |
| `fw-bold` | Applies bold font weight. |
| `text-navy` | Applies the custom navy text color. |
| `shadow-sm` | Adds a subtle shadow to cards. |
| `rounded-4` | Applies rounded corners. |
| `btn` | Provides Bootstrap button styling. |

## JavaScript Concepts

| Method / Concept | Use |
|---|---|
| `alert()` | Displays a welcome message. |
| `document.getElementById()` | Selects the result announcement button. |
| `addEventListener()` | Registers a click event handler. |
| `confirm()` | Requests user confirmation before displaying the result. |
| `if...else` | Executes different actions depending on the user's choice. |
| `document.title` | Updates the browser tab title. |
| `document.body.innerHTML` | Replaces the page content dynamically. |

## Learning Outcomes

- Practice Bootstrap's responsive grid system.
- Apply Bootstrap cards, buttons, and utility classes.
- Understand JavaScript event handling.
- Use conditional statements to control application behavior.
- Practice basic DOM manipulation.
- Understand how JavaScript can change page content dynamically.

## Project Status

Completed for the current learning stage.

This is a frontend practice project using demonstration student information. The result announcement is simulated and is not connected to an actual examination or student database.
