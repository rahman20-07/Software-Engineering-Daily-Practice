# Student Registration Form — HTML & CSS Practice

## 1. Project Overview

A static Student Registration Form developed as part of my continuous frontend development upskilling journey.

The project focuses on practicing HTML form elements, input attributes, browser-based form validation and CSS pseudo-classes.

The webpage contains fields for Student ID, Full Name, Email, Age and Terms & Conditions acceptance.

## 2. Technologies Used

- HTML5
- CSS3

## 3. What I Learned

### HTML Form Elements and Attributes

| Element / Attribute | Purpose |
|---|---|
| `<form>` | Groups form controls for collecting and submitting user input. |
| `<label>` | Provides a descriptive label for an input. |
| `<input>` | Creates an interactive form control. |
| `type="text"` | Accepts general text input. |
| `type="email"` | Accepts email input with built-in validation. |
| `type="number"` | Accepts numeric input. |
| `type="checkbox"` | Creates a selectable checkbox. |
| `type="submit"` | Creates a form submission button. |
| `for` | Associates a label with an input ID. |
| `name` | Defines the name of a form control during submission. |
| `id` | Assigns a unique identifier to an element. |
| `placeholder` | Displays an input hint. |
| `required` | Makes an input mandatory. |
| `readonly` | Prevents users from editing an input value. |
| `value` | Defines the initial input value. |
| `min` | Sets the minimum permitted numeric value. |
| `max` | Sets the maximum permitted numeric value. |

### CSS Selectors and Properties

| CSS Concept | Purpose |
|---|---|
| `min-height` | Sets the minimum height of an element. |
| `clamp()` | Restricts a responsive value between minimum and maximum limits. |
| `max-width` | Sets the maximum width of an element. |
| `gap` | Creates spacing between layout items. |
| `fit-content` | Sizes an element according to its content. |
| `white-space: nowrap` | Prevents text from wrapping. |
| `accent-color` | Changes the accent color of supported form controls. |
| `cursor` | Controls the appearance of the mouse pointer. |
| `transition` | Creates gradual visual changes. |
| `:focus` | Targets an element when it receives focus. |
| `:valid` | Targets form controls with valid values. |
| `:invalid` | Targets form controls with invalid values. |
| `:checked` | Targets selected checkboxes or radio buttons. |
| `:read-only` | Targets elements that cannot be edited. |
| `+` | Selects an immediately adjacent sibling element. |

## 4. Why I Learned These Concepts

- **HTML Forms:** To understand how webpages collect user information.
- **Input Types:** To provide appropriate controls for different kinds of user data.
- **Form Attributes:** To understand mandatory fields, predefined values and input restrictions.
- **Native Validation:** To practice browser-provided input validation without JavaScript.
- **CSS Pseudo-classes:** To style form elements according to their interaction and validation states.
- **Responsive Typography:** To understand how `clamp()` adjusts font sizes within defined limits.
- **CSS Layout:** To practice alignment, spacing and sizing of form components.

## 5. How I Implemented These Concepts

- Created a student registration form using HTML5.
- Added text, email, number and checkbox input controls.
- Connected labels to their respective inputs using `for` and `id`.
- Used `required` to make selected fields mandatory.
- Applied `min` and `max` restrictions to the age input.
- Used `readonly` to display a predefined Student ID.
- Applied CSS pseudo-classes to indicate input validation and interaction states.
- Used Flexbox to center the registration container.
- Applied `clamp()` for responsive heading typography.
- Styled the form using spacing, borders, colors, transitions and box shadows.
