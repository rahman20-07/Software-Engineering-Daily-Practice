# Campus Notice Board — HTML & CSS Practice

## 1. Project Overview

Campus Notice Board is a static college information webpage developed as part of my continuous software engineering upskilling journey.

The project focuses on practicing HTML5 semantic elements and foundational CSS concepts by creating a structured college information portal.

The webpage contains college notices, upcoming event announcements, navigation links and an important-links section.

## 2. Technologies Used

- HTML5
- CSS3

## 3. What I Learned

### HTML Concepts

| HTML Element / Attribute | Purpose |
|---|---|
| `<!DOCTYPE html>` | Declares that the document uses HTML5. |
| `<html>` | Root element that contains the entire webpage. |
| `lang` | Specifies the language of the webpage. |
| `<head>` | Contains webpage metadata and resource information. |
| `<meta charset>` | Defines the character encoding of the document. |
| `<meta viewport>` | Controls the webpage's viewport on different devices. |
| `<title>` | Sets the title displayed in the browser tab. |
| `<style>` | Contains internal CSS styling rules. |
| `<body>` | Contains all visible webpage content. |
| `<header>` | Defines introductory content or a page header. |
| `<nav>` | Defines a section containing navigation links. |
| `<main>` | Identifies the primary content of the webpage. |
| `<section>` | Groups related content into a meaningful section. |
| `<article>` | Represents independent, self-contained content. |
| `<aside>` | Contains additional content related to the main content. |
| `<footer>` | Defines footer information for a page or section. |
| `<h1>` – `<h6>` | Define headings from highest to lowest importance. |
| `<p>` | Defines a paragraph of text. |
| `<a>` | Creates a hyperlink to another location or resource. |
| `<strong>` | Indicates that its content has strong importance. |
| `<ul>` | Creates an unordered (bulleted) list. |
| `<li>` | Represents an individual list item. |

### HTML Attributes

| Attribute | Purpose |
|---|---|
| `charset` | Specifies the character encoding. |
| `name` | Identifies the metadata type in a meta element. |
| `content` | Provides the value of metadata. |
| `href` | Specifies the destination of a hyperlink. |
| `class` | Assigns a reusable name to one or more elements for styling or scripting. |
| `id` | Gives an element a unique identifier within the document. |
| `aria-labelledby` | Connects an element to another element that provides its accessible name. |

### CSS Concepts

| CSS Selector / Property | Purpose |
|---|---|
| `*` | Universal selector that targets all elements. |
| `element selector` | Targets HTML elements by their tag name. |
| `.class` | Targets elements having a specific class. |
| `descendant selector` | Targets elements nested inside another specified element. |
| `margin` | Creates space outside an element's border. |
| `padding` | Creates space between an element's content and border. |
| `box-sizing` | Controls how an element's width and height are calculated. |
| `background-color` | Sets the background color of an element. |
| `color` | Sets the text color. |
| `font-family` | Specifies the font used for text. |
| `font-size` | Controls the size of text. |
| `font-weight` | Controls the thickness of text. |
| `text-align` | Aligns text horizontally within its containing block. |
| `text-decoration` | Adds or removes text decorations such as underlines. |
| `width` | Sets the width of an element. |
| `max-width` | Sets the maximum allowed width of an element. |
| `calc()` | Calculates CSS values using mathematical expressions. |
| `border` | Adds a border around an element. |
| `border-left` | Adds a border specifically to the left side of an element. |
| `border-radius` | Rounds the corners of an element. |
| `list-style` | Controls the markers used in lists. |
| `transition` | Creates a gradual change between CSS property values. |

### CSS Pseudo-classes

| Pseudo-class | Purpose |
|---|---|
| `:hover` | Applies styles when the pointer moves over an element. |
| `:focus-visible` | Applies styles when an element receives keyboard-oriented visible focus. |

## 4. Why I Learned These Concepts

- **Semantic HTML:** To organize webpage content using meaningful elements.
- **Navigation:** To understand how website navigation and hyperlinks work.
- **Content organization:** To separate notices, announcements and related information.
- **Accessibility:** To understand how semantic elements and ARIA attributes help users navigate webpages.
- **CSS selectors:** To target specific elements and apply styling.
- **CSS box model:** To understand element dimensions and spacing.
- **Transitions and pseudo-classes:** To practice adding visual feedback to interactive elements.

## 5. How I Implemented These Concepts

- Created the webpage structure using HTML5.
- Used semantic elements to organize the header, navigation, main content and footer.
- Created separate sections for latest notices and upcoming events.
- Used article elements to represent individual announcements.
- Implemented a navigation menu using the `nav` element and anchor links.
- Created an important-links section using `aside`, unordered lists and anchor elements.
- Associated the aside region with its heading using `aria-labelledby`.
- Applied CSS selectors to style different webpage components.
- Used background colors, typography, margins, padding and borders to improve content presentation.
- Implemented hover transitions for navigation links.

**Note:** Navigation destinations and institutional URLs are illustrative placeholders in this practice implementation.
