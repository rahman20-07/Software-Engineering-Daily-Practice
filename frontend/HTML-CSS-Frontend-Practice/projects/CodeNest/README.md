# CodeNest — Developer Resources Hub

## 1. Project Overview

CodeNest is a static developer resource webpage created as part of my continuous frontend development learning journey.

The project focuses on practicing HTML document structure, semantic elements, internal page navigation, external hyperlinks and foundational CSS styling.

The webpage provides separate sections for HTML, CSS, JavaScript and useful developer learning resources.

## 2. Technologies Used

- HTML5
- CSS3

## 3. What I Learned

### HTML Elements

| HTML Element | Purpose |
|---|---|
| `<!DOCTYPE html>` | Declares the document as HTML5. |
| `<html>` | Root element containing the entire webpage. |
| `<head>` | Contains metadata and resource information. |
| `<meta>` | Provides metadata about the webpage. |
| `<title>` | Sets the title displayed in the browser tab. |
| `<style>` | Contains internal CSS styling rules. |
| `<body>` | Contains all visible webpage content. |
| `<header>` | Defines introductory or header content. |
| `<nav>` | Groups navigation links. |
| `<main>` | Identifies the primary content of the webpage. |
| `<section>` | Groups related content into meaningful sections. |
| `<article>` | Represents independent, self-contained content. |
| `<footer>` | Defines footer information. |
| `<h1>` – `<h3>` | Define headings at different levels. |
| `<p>` | Defines a paragraph. |
| `<a>` | Creates a hyperlink to another location or resource. |
| `<br>` | Inserts a line break. |

### HTML Attributes

| Attribute | Purpose |
|---|---|
| `lang` | Specifies the language of the webpage. |
| `charset` | Defines the document's character encoding. |
| `name` | Identifies the metadata property. |
| `content` | Provides the metadata value. |
| `href` | Specifies the destination of a hyperlink. |
| `id` | Assigns a unique identifier to an HTML element. |
| `target="_blank"` | Opens a hyperlink in a new browsing context. |

### CSS Selectors and Properties

| CSS Selector / Property | Purpose |
|---|---|
| `*` | Universal selector that targets all elements. |
| Element selector | Targets elements using their HTML tag names. |
| Class selector (`.`) | Targets elements having a specific class. |
| Descendant selector | Targets elements nested inside another element. |
| `margin` | Creates space outside an element's border. |
| `padding` | Creates space between content and its border. |
| `box-sizing` | Controls how element dimensions are calculated. |
| `background-color` | Sets the background color of an element. |
| `color` | Sets the text color. |
| `font-family` | Specifies the font used for text. |
| `font-size` | Controls the size of text. |
| `font-weight` | Controls the thickness of text. |
| `line-height` | Controls the vertical spacing between text lines. |
| `width` | Sets the width of an element. |
| `border` | Adds a border around an element. |
| `border-radius` | Rounds the corners of an element. |
| `display: inline-block` | Allows elements to flow inline while supporting block-style dimensions. |
| `text-decoration` | Controls text decorations such as underlines. |
| `transition` | Creates gradual changes between CSS property values. |
| `:hover` | Applies styles when the pointer moves over an element. |

## 4. Why I Learned These Concepts

- **Semantic HTML:** To understand how webpages can be organized using meaningful elements.
- **Navigation:** To understand how users move between different sections of a webpage.
- **Anchor links:** To practice connecting sections using element IDs and fragment identifiers.
- **External hyperlinks:** To understand how to connect webpages with external learning resources.
- **CSS selectors:** To target specific HTML elements for styling.
- **CSS box model:** To understand element spacing and dimensions.
- **Transitions and hover effects:** To practice providing visual feedback during user interaction.
- **Typography and layout:** To improve content readability and visual organization.

## 5. How I Implemented These Concepts

- Created a developer resource webpage using HTML5.
- Organized the content using semantic elements such as `header`, `nav`, `main`, `section`, `article` and `footer`.
- Created internal navigation links to different webpage sections.
- Added separate sections for HTML, CSS and JavaScript learning resources.
- Integrated external learning resources from MDN, W3Schools and GitHub.
- Used CSS selectors to style navigation links, content sections and footer elements.
- Applied margins, padding, borders, colors and typography.
- Implemented hover effects and CSS transitions for navigation and resource links.
