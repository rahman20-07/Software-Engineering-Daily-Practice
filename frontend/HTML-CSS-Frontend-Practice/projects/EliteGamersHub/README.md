# Elite Gamer's Hub

## Project Overview
A static gaming webpage displaying four popular games with their images, descriptions, ratings, platform details, prices, storage requirements, and game modes.

## Technologies Used
- HTML5
- CSS3

## What I Learned

### HTML Concepts

| Element | Purpose |
|---|---|
| `<button>` | Creates a clickable button. |
| `<ul>` | Creates an unordered list. |
| `<li>` | Defines an individual list item. |
| `<img>` | Displays a game image. |
| `<section>` | Groups related content into a section. |

### CSS Concepts

| Property | Purpose |
|---|---|
| `flex-direction` | Controls the direction of Flexbox items. |
| `list-style` | Controls the appearance of list markers. |
| `object-fit` | Controls how an image fits inside its dimensions. |
| `flex-wrap` | Allows Flexbox items to move onto another line. |

## How I Implemented Them
- Created individual game cards using HTML sections.
- Displayed game information using headings, paragraphs, and lists.
- Used Flexbox to arrange four game cards horizontally.
- Added images through relative file paths.
- Applied CSS styling to backgrounds, borders, spacing, and buttons.

## Learning Context
This project is part of my ongoing HTML and CSS practice. It focuses on structuring repeated content into cards and improving layout skills.
