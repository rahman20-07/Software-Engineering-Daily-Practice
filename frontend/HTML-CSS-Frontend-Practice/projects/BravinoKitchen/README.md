# BravinoKitchen — Restaurant Menu Webpage

## 1. Project Overview

BravinoKitchen is a static restaurant menu webpage developed as part of my frontend development upskilling journey.

The webpage showcases three food items — Veg Burger, Italian Pizza, and Chocolate Cake — along with food descriptions, pricing information, promotional offers, and a footer section.

## 2. Technologies Used

- HTML5
- CSS3

## 3. What I Learned

### HTML Concepts
- HTML5 document structure and metadata.
- Semantic elements: `header`, `section`, and `footer`.
- Heading hierarchy (`h1`, `h2`, `h3`).
- Paragraphs and image embedding.
- Relative paths for referencing local images.
- Text formatting elements: `b`, `i`, `u`, `del`, and `mark`.
- Special characters and symbols.

### CSS Concepts
- Universal, element, class and descendant selectors.
- Background colors and text colors.
- Font families and font sizes.
- Margin and padding.
- Text alignment.
- Border radius.
- Box shadows.
- Image dimensions and spacing.

## 4. Why I Learned These Concepts

- **HTML structure:** To understand how webpage content is organized.
- **Semantic elements:** To give meaningful structure to webpage sections.
- **Text formatting:** To present important information, offers and pricing.
- **CSS selectors:** To target specific elements and apply styling.
- **Box model:** To understand spacing and layout around elements.
- **Typography and colors:** To improve readability and visual presentation.
- **Borders and shadows:** To create visually distinct content sections.

## 5. How I Implemented Them

- Structured the webpage using HTML5.
- Created a header, individual food menu sections, and a footer.
- Embedded food images using relative file paths.
- Used text formatting elements to highlight promotional offers and prices.
- Applied CSS selectors to style different webpage components.
- Used margins, padding, rounded corners and box shadows to distinguish menu sections.
- Applied typography and background colors to establish a consistent visual appearance.

## 6. Learning Context

This project represents my practical application of foundational HTML and CSS concepts as part of my continuous software engineering upskilling journey.
