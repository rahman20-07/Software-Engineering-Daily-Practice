# Hospital Management System

## Project Overview

A static Hospital Management System webpage created using HTML5 and CSS3. It displays sample doctor information, patient details, appointment schedules, fee details, and medical test reports using structured HTML tables.

## Technologies Used

- HTML5
- CSS3

## What I Learned

### HTML Concepts

| Element / Attribute | Purpose |
|---|---|
| `<table>` | Creates a table for displaying structured data. |
| `<thead>` | Groups the header rows of a table. |
| `<tbody>` | Groups the main data rows. |
| `<tfoot>` | Groups the footer rows of a table. |
| `<tr>` | Defines a table row. |
| `<th>` | Defines a header cell. |
| `<td>` | Defines a standard data cell. |
| `colspan` | Allows a cell to span multiple columns. |
| `rowspan` | Allows a cell to span multiple rows. |
| Nested tables | Place one table inside another table cell. |

### CSS Concepts

| Property | Purpose |
|---|---|
| `border-collapse` | Controls whether adjacent table borders are combined. |
| `vertical-align` | Controls vertical alignment of inline or table-cell content. |
| `padding` | Adds space inside table cells. |
| `background-color` | Sets the background color of table cells. |

## How I Implemented Them

- Created the hospital information dashboard using HTML tables.
- Organized doctor and patient information into separate tables.
- Used nested tables for doctor qualifications and fee details.
- Used `colspan` and `rowspan` to merge table cells.
- Used `<thead>`, `<tbody>`, and `<tfoot>` to organize table sections.
- Applied CSS borders, colors, padding, and alignment.

## Project Limitations

This is a static HTML and CSS practice project. It uses sample hospital data and does not include database connectivity, authentication, appointment booking, or backend functionality.

## Learning Context

This project is part of my ongoing HTML and CSS practice, focusing on structured tabular data and advanced HTML table layouts.
