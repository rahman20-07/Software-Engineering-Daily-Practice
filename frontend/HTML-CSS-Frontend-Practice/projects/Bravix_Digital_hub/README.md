# Bravix Digital Hub — Electronics Product Showcase

## 1. Project Overview

Bravix Digital Hub is a static electronics product showcase webpage developed as part of my frontend development upskilling journey.

The webpage displays three electronic products: Laptop, Smart Mobile and Smart Watch, along with product descriptions, pricing information, availability details and a promotional offer.

## 2. Technologies Used

- HTML5
- CSS3

## 3. What I Learned

### HTML Concepts
- HTML5 document structure and metadata.
- Semantic elements: `header`, `main` and `section`.
- Heading hierarchy.
- Paragraph and inline elements.
- Image embedding using relative paths.
- Special characters and currency symbols.

### CSS Concepts
- Universal, element and class selectors.
- CSS box model and `box-sizing`.
- Flexbox layout using `display: flex`.
- Content alignment using `justify-content`.
- Background colors and typography.
- Margin and padding.
- Image dimensions and styling.
- Inline element styling.

## 4. Why I Learned These Concepts

- **Semantic HTML:** To organize webpage content meaningfully.
- **CSS selectors:** To target and style specific elements.
- **Box model:** To understand element dimensions and spacing.
- **Flexbox:** To arrange multiple product sections along a flexible layout.
- **Typography and colors:** To improve readability and visual presentation.
- **Image styling:** To control how product images appear within webpage sections.

## 5. How I Implemented Them

- Created a webpage structure using HTML5.
- Designed a header and promotional offer section.
- Used Flexbox to arrange three product sections horizontally.
- Integrated local product images using relative file paths.
- Displayed product descriptions, prices and availability information.
- Applied CSS styling through element and class selectors.
- Used padding, margins, colors and typography to style webpage components.

## 6. Learning Context

This project represents my practical application of HTML5, CSS fundamentals and introductory Flexbox concepts during my continuous software engineering upskilling journey.
