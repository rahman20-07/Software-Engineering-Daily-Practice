# TuneBox Music Player

## Project Overview

TuneBox is a static music-player interface built using HTML5 and CSS3. It includes a navigation bar, song search field, featured music section, playlist cards, and a bottom music-player section.

## Technologies Used

- HTML5
- CSS3

## What I Learned

### HTML Concepts

| Element / Attribute | Purpose |
|---|---|
| `<link>` | Connects an external CSS file to an HTML document. |
| `<nav>` | Defines the navigation section. |
| `<label>` | Provides a label for a form control. |
| `<input type="search">` | Creates a search input field. |
| `for` | Connects a label to an input using its ID. |
| `<article>` | Represents an individual song card. |
| `aria-label` | Provides an accessible name for the navigation region. |

### CSS Concepts

| Property / Feature | Purpose |
|---|---|
| `display: grid` | Creates a grid-based layout. |
| `auto-fit` | Adjusts the number of grid columns to available space. |
| `minmax()` | Defines minimum and maximum grid track sizes. |
| `clamp()` | Sets a responsive value within a defined range. |
| `white-space` | Controls how text handles whitespace and wrapping. |
| `outline-offset` | Controls the spacing between an outline and an element. |
| `:focus` | Applies styles when an element receives focus. |
| `transition` | Creates smooth changes between CSS property values. |
| `@media` | Applies styles based on screen conditions. |
| `flex-shrink` | Controls how a flex item shrinks when space is limited. |

## How I Implemented Them

- Created a music-player interface using semantic HTML elements.
- Connected an external stylesheet using the `<link>` element.
- Added navigation links using internal page identifiers.
- Created a song search field with an associated label.
- Designed individual song cards using HTML articles.
- Used CSS Grid to arrange the playlist.
- Used Flexbox to align navigation items and song information.
- Added hover and focus styling to improve visual interaction.
- Applied media queries for smaller screens.

## Project Limitations

This is a static frontend practice project. Search, playlist selection, and music playback are not connected to JavaScript functionality or an audio source.

## Learning Context

This project is part of my ongoing HTML and CSS practice. It focuses on combining CSS Grid, Flexbox, responsive styling, semantic HTML, and form controls in a single interface.
