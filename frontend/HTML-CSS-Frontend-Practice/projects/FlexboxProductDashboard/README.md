# ShopFlex — Responsive Product Dashboard

## Project Overview

ShopFlex is a static e-commerce product dashboard developed using HTML5 and CSS3. It displays a product collection with a navigation bar, hero section, product cards, and footer.

The main objective was to practice CSS Flexbox, CSS Grid, and responsive webpage layouts.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## What I Learned

### HTML Concepts

| Element / Attribute | Purpose |
|---|---|
| `<nav>` | Defines the navigation area of the webpage. |
| `<article>` | Represents an individual product card. |
| `<span>` | Displays inline content such as product prices. |
| `aria-label` | Provides an accessible name for the navigation region. |
| `id` | Identifies sections for internal page navigation. |

### CSS Concepts

| Property / Feature | Purpose |
|---|---|
| `display: grid` | Creates a grid-based layout. |
| `grid-template-columns` | Defines the columns of a grid. |
| `repeat()` | Repeats a grid track pattern. |
| `auto-fit` | Adjusts the number of grid columns to available space. |
| `minmax()` | Defines minimum and maximum grid track sizes. |
| `1fr` | Represents a fraction of available grid space. |
| `@media` | Applies CSS rules based on screen conditions. |
| `position: sticky` | Keeps an element visible while scrolling within its container. |
| `z-index` | Controls the stacking order of positioned elements. |
| `scroll-behavior` | Controls scrolling behavior for navigation. |
| `object-fit: contain` | Fits an image inside its dimensions without cropping it. |
| `flex-wrap` | Allows Flexbox items to wrap onto additional lines. |

## Why I Learned These Concepts

To understand how CSS Grid and Flexbox can be combined to build structured product layouts that adapt to different screen sizes.

## How I Implemented Them

- Created a navigation bar using Flexbox.
- Implemented a sticky header with CSS positioning.
- Designed a hero section using Flexbox.
- Created product cards using CSS Grid.
- Used `auto-fit`, `minmax()`, and fractional units for adaptable grid columns.
- Used Flexbox inside product cards to organize their content.
- Added mobile-specific layout changes using a media query.
- Applied image sizing, spacing, hover effects, and visual styling.

## Project Limitations

This is a frontend practice project. The product information is sample content, and the purchase buttons are not connected to a shopping cart, payment system, or backend.

This project is part of my ongoing software engineering learning journey. It focuses on improving my understanding of responsive layouts, CSS Grid, Flexbox, and semantic HTML through practical implementation.
