# HTML List Practice

## Project Overview

A collection of five HTML practice exercises demonstrating different list structures and content grouping elements.

## Technologies Used

- HTML5

## Practice Files

| File | Description |
|---|---|
| `DefinitionList.html` | Demonstrates definition lists using `<dl>`, `<dt>`, and `<dd>`. |
| `FavoriteFruitsList.html` | Demonstrates an unordered list of favorite fruits. |
| `Fieldset.html` | Demonstrates `<fieldset>` and `<legend>` for grouping related content. |
| `Nested_DefinitionList.html` | Demonstrates nested definition lists for organizing technology categories and descriptions. |
| `OrderedList.html` | Demonstrates ordered lists and the `type` attribute. |

## What I Learned

| HTML Element / Attribute | Purpose |
|---|---|
| `<dl>` | Creates a description list. |
| `<dt>` | Defines a term in a description list. |
| `<dd>` | Provides a description or explanation of a term. |
| Nested `<dl>` | Organizes related terms and descriptions into nested groups. |
| `<ol>` | Creates an ordered list. |
| `type` | Specifies the numbering style of an ordered list. |
| `<fieldset>` | Groups related form controls. |
| `<legend>` | Provides a caption for a fieldset. |

## Learning Context

These exercises are part of my ongoing HTML learning practice. They focus on understanding list structures, nested descriptions, ordered lists, and content grouping using native HTML elements.
